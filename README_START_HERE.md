## Quick start on Windows

1. Open this folder in VS Code.
2. If no .venv exists, double-click `01_SETUP_WINDOWS.cmd`.
3. Double-click `02_RUN_APP_WINDOWS.cmd`, or use the following in VS Code Terminal:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

4. Open the `PROMPTS_Codex_Day2_Copy_Paste.txt` file in the *parent Participant Kit* and start at P01.
5. Do not paste all prompts at once. Verify file changes and checkpoints after every prompt.
